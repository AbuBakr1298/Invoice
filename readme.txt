html2pdf.js v0.10.1  (MIT License, see LICENSE)
Creates the invoice PDF in the visitor's browser. Loaded on demand by assets/js/invoice.js.

File:    html2pdf.bundle.min.js  (unmodified official release build)
Source:  https://github.com/eKoopmans/html2pdf.js  (tag v0.10.1, file dist/html2pdf.bundle.min.js)
SHA-256: 85e6ee9ce246e3ae4424313f7e46a5ed860a28d757811de8dc9c43f306049d65

The bundle contains html2canvas, jsPDF and other open-source libraries. Their licence notices are in
html2pdf.bundle.min.js.LICENSE.txt, which must stay next to the script.

To upgrade: put the new version in a new folder (assets/vendor/html2pdf-<version>/) and update the path in
assets/js/invoice.js. The folder name carries the version so that browsers can cache it for a year.
